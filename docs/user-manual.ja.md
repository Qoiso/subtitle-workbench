# Subtitle Workbench ユーザーマニュアル（簡易版）

## 1. 素材結合

1. 「素材結合」で少なくとも2種類の素材を選択します（動画/画像、音声、字幕）。
2. 出力形式と出力品質を選択します。
3. 「結合開始」を押して、右側ログで進捗を確認します。

注意：
- 画像入力またはハード字幕を使う場合、`-c copy` のロスレス結合は使えません。

## 2. 動画ダウンロード

1. 動画 URL を入力します。
2. 保存先と Cookie モード（任意）を設定します。
3. 「動画画質を取得」で画質を選びます（自動最適/Video Only/Audio Only）。
4. 「ダウンロード開始」を実行します。

## 3. 動画字幕化

プリセット：
- ワンクリック標準字幕化
- ワンクリック音声字幕化
- ステップ字幕化

ローカル ASR：
1. `faster-whisper（ローカル）` を選択
2. モデルをダウンロード/起動
3. タスク実行

クラウド ASR：
1. バックエンドを選択（Gemini/OpenAI/Qwen/カスタム）
2. API URL、トークン、モデル名を設定
3. 「ASR接続テスト」を実行
4. タスク実行

## 4. 設定

- ffmpeg/ffprobe パス設定
- 背景ぼかし・オーバーレイ透明度
- 環境チェック

## 5. 保存先

- 設定：`%APPDATA%/ff-merge/config.json`
- 背景/プレビュー：`%APPDATA%/ff-merge/backgrounds/`
- ログ：`%APPDATA%/ff-merge/logs/`
