# Subtitle Workbench 用户手册（简版）

## 1. 素材合并

1. 在“素材合并”页上传至少两类素材（视频/图片、音频、字幕）。
2. 选择输出格式与输出质量。
3. 点击“开始合并”，在右侧查看进度与日志。

注意：
- 选择图片或硬字幕时，无法使用无损合并（`-c copy`）。

## 2. 视频下载

1. 输入视频 URL。
2. 选择下载目录与 Cookie 模式（可选）。
3. 点击“获取视频清晰度”，选择质量（自动最佳/仅视频/仅音频）。
4. 点击“开始下载”。

## 3. 视频字幕化

可选模式：
- 一键标准汉化
- 一键音声汉化
- 分步骤汉化

本地 ASR：
1. 选择 `faster-whisper（本地）`
2. 选择模型并下载/启动
3. 执行任务

云端 ASR：
1. 选择云端后端（Gemini/OpenAI/Qwen/自定义）
2. 填写 API 地址、令牌和模型名
3. 先点“测试ASR连接”
4. 再执行任务

## 4. 设置页

- 可配置 ffmpeg/ffprobe 路径
- 可调背景模糊与遮罩透明度
- 可进行环境检测

## 5. 配置与日志

- 配置：`%APPDATA%/ff-merge/config.json`
- 背景与预览图：`%APPDATA%/ff-merge/backgrounds/`
- 日志：`%APPDATA%/ff-merge/logs/`
